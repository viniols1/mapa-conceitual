# Mapa Conceitual: Evolução da Organização Urbana

Este é um projeto acadêmico desenvolvido como atividade para a Universidade Presbiteriana Mackenzie. O objetivo é apresentar um mapa conceitual interativo sobre a evolução dos conceitos de organização urbana, baseado nos temas da "Aula 3 de Ciência, Tecnologia e Sociedade".

## 🚀 Sobre o Projeto

O projeto consiste em uma página web estática que exibe diversos conceitos-chave (como *Pólis*, *Civitas*, *Metrópole*, etc.) de forma visual. Ao clicar em cada conceito, uma janela modal (popup) é exibida com a definição detalhada do termo.

O design foi pensado para apresentações acadêmicas, utilizando um fundo escuro com detalhes em azul para facilitar a visualização e o foco no conteúdo.

## ✨ Funcionalidades

* **Mapa Interativo:** Conceitos apresentados como "nós" clicáveis.
* **Modais de Informação:** Janelas popup que surgem ao clicar em um conceito, exibindo seu título e definição.
* **Design Limpo:** Foco na legibilidade, com tema escuro (preto e azul).
* **Estrutura Organizada:** O código é separado em arquivos `index.html`, `style.css` e `script.js` para facilitar a manutenção.

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram usadas na construção deste projeto:

* **HTML5:** Para a estrutura semântica do conteúdo.
* **CSS3:** Para a estilização, layout (posicionamento absoluto) e animações.
* **JavaScript (ES6+):** Para manipular o DOM e criar a interatividade dos modais (popups).
